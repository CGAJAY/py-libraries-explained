# 🐍 Py Libraries Explained

Welcome to **Py Libraries Explained** — a beginner-friendly repository that teaches you how to use popular Python libraries with simple, well-commented examples.

This project is designed for **new learners** and **students** who want to understand how Python third-party packages work in real-life scenarios.

---

## 📚 Available Libraries

Each Python library is organized in its **own branch**, so you can focus on one library at a time.

| Library    | Branch Name    | Description                                         |
| ---------- | -------------- | --------------------------------------------------- |
| Pandas     | [`pandas`]     | Learn how to work with arrays and numerical data.   |
| Matplotlib | [`matplotlib`] | Learn how to visualize data using charts and plots. |
